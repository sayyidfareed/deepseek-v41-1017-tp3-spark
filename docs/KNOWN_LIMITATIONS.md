# Known limitations

- **Slowdowns:** bounded text/image prefill scheduling and decode-service fixes are included and passed synthetic mixed-workload checks. Intermittent low throughput and long first-token delays have occurred; these fixes do not establish sustained mixed-workload performance or explain every pause. The 250 ms allowance budgets decode service, not a maximum prefill or SSE pause. The accepted 1K competing-prefill profile prioritizes ongoing replies: in one matched 320K cold-image pair, peer output rose from 7.03 to 38.83 visible tok/s and worst gap fell from 1.12 to 0.82 s, while cold-image first output increased from 159 to 244 s. This tradeoff does not establish broad workload performance.
- **Long contexts:** twelve request slots do not guarantee twelve simultaneous long histories. Near-1M context operation is not qualified.
- **Reasoning:** malformed or unmarked thinking blocks can still leak into answer text. Incremental streaming remains enabled.
- **JSON schemas:** root or nested `anyOf`/`oneOf` object unions return HTTP 422. JSON-object fallback requires client-side validation.
- **Caching:** TP2 and TP3 spill caches are not interchangeable. In-memory cache is lost on shutdown; no cross-topology migration is provided. Two fresh synthetic 32K image histories successfully restored 30,720 tokens each from disk across a normal same-build restart. Earlier diagnostic-mode starts missed their checkpoints; that difference remains unexplained. This does not qualify every historical cache or cross-build reuse.
- **Retention:** ordinary disk spill retains conversation-derived state. No secure/no-retention qualification is claimed.
- **Installation:** source reconstruction is tested; fresh-machine runtime assembly and deployment of this public packaging are not. There is no bundled image, automatic network setup or service supervisor.
- **64 KiB hosts:** ordinary API, short C1/C4/C8/C12, image/cache and cancellation checks passed on the tested 64 KiB kernel and Memory Saver. Low clocks recovered after a controlled power disconnect; no throughput gain is attributed to the kernel alone. The original README benchmark table predates this host qualification. Engram read-ahead, restore polling and competing-prefill repairs passed bounded GPU tests. They do not establish that every historical pause is fixed.
